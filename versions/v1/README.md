# 뉴스의 주제와 조회수

2025년 공개 일반 영상 1,680개를 분석한 16장 HTML 발표입니다.

index.html을 열거나 GitHub Pages에서 발표합니다. 방향키/Space 이동, N 노트, O 목차, F 전체화면.

source.csv: Firecrawl 수집 원자료. research_data.json: 전체 사전·집계·영상별 태그. analysis.py: pandas/numpy로 재현하는 분석 코드. collection_report.md: 원수집 방법과 제한.

조회수는 2026-10-18 누적값입니다. 단어 사전 기반 탐색 비교이며 인과 추론이나 방송사 전체의 성과 순위를 뜻하지 않습니다.
