# V6 구성과 시각화

제작 전 계획은 [V6 수정 계획](v6_revision_plan.md)에 있다. 최신 사용자 지시에 따라 V5의 연구 내용과 15장 순서를 유지하면서 표현을 개선했다. 새로운 수집·분류·연구 결론은 추가하지 않았다.

핵심 연구 질문은 “방송사 뉴미디어 뉴스 채널에서 콘텐츠 주제에 따라 조회수는 어떻게 달라지는가?”이다. 제목 표현은 운영자의 실제 기획을 위한 확장 분석이다. 원본 1,680편의 수집·분석 범위와 2026-10-18 누적 조회수 기준을 유지한다.

|장|역할과 메시지|시각화·연출|
|---|---|---|
|1|뉴미디어 뉴스, 왜 어떤 영상은 더 많이 볼까?|큰 제목, 작은 실제 영상 콜라주, 1,680편 카운트업|
|2|운영자의 주제·제목 선택과 연구 질문|기존 두 결정과 핵심·확장 질문 유지|
|3|공식 5개 채널의 일반 영상 1,680편|프로필·실제 영상, 채널별 편수 카운트업|
|4|복수 주제 태그와 채널 안 상위권 정의|실제 아이패드 영상·두 태그·100점 도식 유지|
|5|전체 주제 태그의 제작 분포|8개 막대 순차 등장, 제작 수·전체 대비 비중|
|6|채널마다 다른 제작 편성|기존 5×8 히트맵, 행 순차 등장|
|7|제작 비중과 상위권 비중은 분모가 다름|네이비 막대·오렌지 점, 분모와 684/1,680·196/684 예시|
|8|같은 음식 태그에서도 채널 차이|실제 영상 2개, 33%·13% 카운트업|
|9|제목의 다섯 단어 규칙|왜·이유·비밀·정체·원리, 실제 포함·미포함 제목 유지|
|10|미포함 23%·포함 35%라는 관찰|숫자 카운트업, 100점 도식, 짧은 비교 테두리 강조|
|11|제목 집단의 차이는 채널마다 다름|회색 빈 원·라임 채운 원으로 통일, 채널 행 순차 등장|
|12|비디오머그 경제·소비 181편으로 범위 축소|실제 제목/썸네일 반례, 45%·33% 카운트업|
|13|제작·채널·제목에서 얻은 세 단서|기존 세 관찰과 해석 유지|
|14|내 채널의 취재 질문과 제목 비교|실제 PB 영상, 큰 취재 질문·제목 A/B·유지/수정 결정|
|15|다음 기획에서 검증할 단서와 한계|기존 결론·실제 영상 띠·부록·PDF 링크 유지|

7장은 같은 퍼센트라도 분모와 용도가 다름을 먼저 읽게 한다. 11장은 채널 이름을 중립색으로 두어 색이 포함 여부만 뜻하게 한다. 14장의 클릭률 정의·7일/28일 기록·무작위 비교 불가 시 해석 범위는 발표 노트와 부록의 ‘가상 PB 기획의 검증 절차’에 남겼다.

1920×1080, Pretendard, 네이비·라임, 여백과 원본 이미지 비율을 유지했다. 표지는 제목 영역을 넓히고 1,680편 통계를 보조 정보로 줄였다. Anime.js는 숫자 760ms, 도형 330~550ms의 절제된 연출에 사용한다. 전체 연출은 1,450ms 안에 최종화한다. 축·기준선은 고정하고 정지 상태에도 전체 정보가 있다.

브라우저·실제 모바일·애니메이션 중간/최종 상태·PDF 검사를 거쳐 SVG 기준선 레이블과 초기 애니메이션 정지 문제를 보완했다. 검증 범위·수정 루프는 [QA 기록](qa_report.md)에 있다. 실제 청중을 모집한 이해도 실험은 수행하지 않았으며 초독 관점의 자체 검토로 구분한다.
