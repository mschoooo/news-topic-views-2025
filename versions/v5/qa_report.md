## 발견하고 수정한 문제

- 이미지 높이와 그리드 최소 폭 때문에 생긴 늘어짐·표지 이탈을 수정했다.
- 모바일 부록의 긴 해시를 줄바꿈하도록 수정했다.
- 7·8장 하단 설명과 페이지 번호의 간격,11장 SVG 기준선 레이블을 수정했다.
- PB·클릭률 뜻, 숫자 주변 띄어쓰기, 긴 제목의 단어 줄바꿈을 보강했다.
- 제목과 썸네일 텍스트가 다름을 확인하고12장에 분석 범위로 명시했다.
- 기본 모드에서 초기 로딩 중 애니메이션이 지연되는 경우를 확인했다. 투명도 변화는 제거하고, 이동 효과도 700ms 안에 정지 상태로 마무리하도록 보강했다. 기본 애니메이션·전체화면·노트·목차·키보드·스와이프를 추가로 검증했다.

## 공개 배포 검증

이 문서는 고정 보관본의 로컬·PDF 검증 기록이다. 실제 공개 URL에서 수행한 파일·이미지·조작·기존 버전 보존 검증은 배포 후 [V5 배포 검증 JSON](https://mschoooo.github.io/news-topic-views-2025/deployments/v5.json)에 별도로 기록한다. V5 고정 보관본을 배포 후 검증 결과 때문에 덮어쓰지 않는다.


## V4 공개 QA에서 발견한 문제와 V5 보정

V4는 데스크톱 창 크기 조절과 데스크톱 조작 검사를 통과했지만, 실제 모바일 브라우저 모드에서 화면 확장을 확인했다. 390px 레이아웃의 clientWidth와 달리 innerWidth가 1560px로 커졌고, 이를 다시 슬라이드 배율 계산에 써 가로 넘침이 유지됐다. 데스크톱 창 크기 조절만으로는 잡지 못한 문제다.

V5는 배율 계산을 document.documentElement.clientWidth/clientHeight 기준으로 바꿨다. 실제 모바일 모드(is_mobile·has_touch)에서 세로390×844·가로844×390으로 전15장을 각각 확인했다. 30개 상태 모두 scrollWidth=clientWidth였고 슬라이드가 화면 안에 들어왔다. 원래390px 화면이390px로 유지되며 실제 터치 이동·노트도 통과했다. 데이터·통계·스토리·이미지·디자인은 V4와 같다.

이미 고정한 V4를 덮어쓰지 않고 V5로 보정했다. V4의 공개 QA 실패와 원인은 [V4 배포 기록](https://mschoooo.github.io/news-topic-views-2025/deployments/v4.json)에 남긴다. V4는 최종본이 아닌 중간 검증본이다.
