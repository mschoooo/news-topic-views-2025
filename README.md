# 다음 영상의 주제와 제목 — V4 최종본

[HTML 발표](https://mschoooo.github.io/news-topic-views-2025/?v=4) · [15페이지 PDF](https://mschoooo.github.io/news-topic-views-2025/versions/v4/news-topics-v4.pdf) · [상세 부록](https://mschoooo.github.io/news-topic-views-2025/appendix.html) · [버전 기록](https://mschoooo.github.io/news-topic-views-2025/versions/)

뉴미디어 정보 채널 운영자의 기획 고민에서 출발해, 방송사 5개 채널의 2025년 일반 영상 1,680편을 살펴보는 탐색 발표다. 핵심 연구 질문은 “방송사 뉴미디어 뉴스 채널에서 콘텐츠 주제에 따라 조회수는 어떻게 달라지는가?”이다. 제목 표현은 실무적 확장 분석으로 구분한다.

본문은 15장이다. 실제 채널 프로필 5개와 검증된 실제 영상 썸네일 9개를 사용했다. 주제 전체 편성→채널 차이→제목의 실제 정의·사례→성과→가상 기획의 검증 순서로 구성했다. 관찰한 차이를 인과효과나 미래 성공확률로 해석하지 않는다.

원본 source.csv는 7열, 1,680행이며 변경하지 않았다. research_data.json과 analysis.py는 V3의 규칙·수치를 유지한다. analysis_review.py와 v4_metrics.json에 추가 제작 비중과 검산을 기록했다. `python analysis.py`, `python analysis_review.py`, `python build_v4.py` 순서로 같은 폴더에서 재현할 수 있다. pandas/numpy가 필요하다.

발표 조작: 방향키·Space 이동, N 노트, O 목차, F 전체화면. PDF는 한 슬라이드당 한 페이지의 16:9 고정본이다. 상세 부록은 별도 웹페이지다.

이미지 권리는 각 제작사에 있으며 출처와 영상 링크를 함께 보존했다. 썸네일은 확보 시점의 표시 상태이고 과거 수정 이력은 분석하지 않았다. Anime.js(MIT)와 Pretendard(OFL) 라이선스는 assets에 있다. V1~V3 고정본과 PDF를 보존한다.
