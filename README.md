# 다음 영상의 주제와 제목 — V3

운영자의 콘텐츠 기획을 위한 탐색 발표입니다. 연구 질문과 원본 1,680개를 유지하고, 전체 주제 현황→채널별 차이→제목의 정의·예시→성과→실제 기획 결정 순서로 재구성했습니다. 본문17장+부록3장입니다.

[현재 발표](https://mschoooo.github.io/news-topic-views-2025/) · [V3 PDF](https://mschoooo.github.io/news-topic-views-2025/versions/v3/news-topics-v3.pdf) · [버전 기록](https://mschoooo.github.io/news-topic-views-2025/versions/)

상위권은 채널별 조회수순 상위25%이며 미래 성공확률이 아닙니다. 주제는 중복 가능한8개 사전 태그, 설명형 표현은 왜·이유·비밀·정체·원리 중 하나를 포함한 경우입니다. 실제 성과와 새 기획·제목의 가상 예시를 구분합니다. 인과 효과를 추정한 실험이 아닙니다.

source.csv: Firecrawl 원자료. research_data.json: 전체 주제 분포·성과와 영상별 태그·표현. analysis.py: pandas/numpy로 재현하는 코드(`python analysis.py`). improvement_plan.md: V3 구성안과 초독 점검 기준.

HTML은 방향키/Space 이동, N 노트, O 목차, F 전체화면을 지원합니다. V1/V2 고정 보관본과 PDF를 유지합니다.

Anime.js3.2.2(MIT), Pretendard1.3.9(OFL) 라이선스는 assets에 포함돼 있습니다.
